# Personalise, Don't Templatise

You do not need to install anything to try this once: copy this whole file, paste it as your first message in any AI chat tool, then follow it with your actual inputs.

Send one consistent template, personalised with real detail. The template exists so the only decision left is what to personalise, not how to restructure the message.

## Gather the Inputs

- The real detail worth personalising: something specific from the actual conversation or event, not a generic restatement
- Whether any referenced resource actually exists and has a working link; confirm rather than assume either way
- How many people this is actually going to; one recipient changes the address form, more than one changes it differently again
- Whether a recipient needs to forward part of this to someone who was not there

## Personalise It

- **Opening line**: the specific thing that actually happened or was said, not a generic line that would read the same for anyone
- **Resource references**: name what the resource actually covers for this recipient specifically, unless nothing more specific is available
- **Named people**: used by name where established

## Handle the Template

Follow the fixed structure exactly. Do not reorder, merge, or rewrite sections to make it "flow better." A fixed template earns its keep specifically because deviation is not a decision the personalising step gets to make.

## Handle More Than One Recipient

If this is going to more than one person, address the group directly. Everyone named is part of the "you" of the message. Never pick one person as the addressee and describe the others in the third person, that is the single most common way this goes wrong.

If it is a single recipient, no other name should appear in the second person, and nobody else should be written as though they are party to the message.

## Handle a Recipient Forwarding to Someone Not There

This is different from more than one recipient. The recipient's own opening line and personalisation stay exactly as the template describes; the message is still written to them. Add one clearly separated block meant specifically for the person they are forwarding to, addressed in the third person as something to forward, never written as if that person is reading the message themselves.

## Apply the Guardrails

- Never refer to the primary recipient in the third person anywhere, even when someone else is mentioned
- Never send a placeholder link or reference; if a resource is not ready, say so rather than sending early
- Never invent an offer or commitment that was not actually discussed

## Stop When the Task Is Unsafe

Do not produce a finished message when:

- Whether a referenced resource actually exists cannot be confirmed either way
- No specific detail is available to personalise the opening line
- It is unclear whether this is a single recipient, multiple recipients, or a forward-to-someone-else case

## Require Human Review

This drafts the message. Sending it stays subject to explicit human approval.
