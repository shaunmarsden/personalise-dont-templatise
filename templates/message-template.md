# Message Template

Keep this structure identical every time; only the bracketed parts change.

---

Hi [Name(s), all recipients if more than one],

[Opening line: something specific that actually happened, not generic]

[Resource line: what this actually covers for this recipient, if a resource exists and has a working link]

[Fixed closing line]

---

## If Forwarding to Someone Not There

Add a clearly separated block after the message above, written in the third person about the recipient and the resource, never addressed as though the other person is reading this directly.
