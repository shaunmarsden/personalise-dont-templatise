# Human Review Checklist

Check these before you send.

- [ ] The opening line and resource reference are specific to this recipient, not generic filler
- [ ] Nobody reordered, merged or rewrote the template structure
- [ ] If there's more than one recipient, each is addressed directly and none is pushed into the third person
- [ ] Any block meant for forwarding is clearly separate and written in the third person
- [ ] No placeholder link went out, and nothing was invented that wasn't discussed
