# Human Review Checklist

Run through this before sending.

- [ ] The opening line and resource reference are specific to this recipient, not generic filler
- [ ] The template structure was not reordered, merged, or rewritten
- [ ] Every recipient is addressed directly if there is more than one, none sidelined into the third person
- [ ] A forward-to-someone-else block, if present, is clearly separated and written in the third person
- [ ] No placeholder link was sent, and nothing was invented that was not actually discussed
