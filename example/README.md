# Worked Example

A fictional photography workshop's follow-up template, used in three different situations without its structure ever changing.

- [the-fixed-template.md](the-fixed-template.md): the template itself, never restructured
- [inputs.md](inputs.md): three cases (a single recipient, two recipients together, and one recipient forwarding to someone who wasn't there)
- [output.md](output.md): the three drafted messages
- [review.md](review.md): whether the template stayed fixed, whether both people in the two-person case were addressed directly, and whether the forwarding block was kept apart from the recipient's own message

The repository doesn't record which model wrote this output, or whether it knew what the test was checking. Read it as an illustration of what a good run looks like, not as a logged run.
